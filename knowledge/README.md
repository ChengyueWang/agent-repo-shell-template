# Knowledge

Keep durable findings and cross-repository decisions here. Organize by topic as
needed; an Obsidian vault is optional. Target-specific engineering documentation
belongs in the owning target.

Each fact has one maintained source. Link summaries and views to that source
instead of keeping independently edited copies. Distinguish evidence (sources,
methods, measurements) from interpretation, and link conclusions to evidence.
Record dates and provenance when they affect how a finding should be used.

Read notes on demand. Shared persistent instructions live in root `AGENTS.md`;
operation-specific procedures live in skills. This repository does not capture
session transcripts. Distill useful findings here and actionable work into tasks.
